# Axon Ivy Express

Axon Ivy Express is an add-on module for the Axon Ivy Portal. As a business user, it enables you to create and share your process applications with your colleagues. These capabilities are also known as No-Code Application Platforms or Citizen Developer Platforms. Therefore, it is the perfect tool to digitize your processes and create standardization, reliability, and traceability. Axon Ivy Express:

   * Allows business users to create processes without an IT background.
   * Automates business processes without IT department involvement.
   * Supports all standard features such as email notifications, task delegation, etc.
   * Features an importer tool to hand over your No-Code business processes to Low-Code or Pro-Code developers.

## Demo

### Create a new Express process

1. Start the Axon Ivy engine
2. Open the **Processes** page
3. Click on **Express Management** process to navigate to the Express management dashboard.

![Express Management process](images/express-management-process.png)

4. In the **Express Management**, click the **Create** button

5. The **Workflow properties** page is opened

![Workflow properties](images/workflow-properties.png)

#### Define workflow properties

1. Define the **Type of process**:

   * Use the option *One time* if you want to execute the process only once.
   * Use the option *Repeatable* if you want to save the process for repetitive use. The process will appear in the table on the **Express-Management** page.

2. Define your **User Interface** :

   * With the option *Create own* you can create your own user dialog for each process step
   * With the option *Use default*, the user dialogs will automatically be generated by Axon Ivy Express

3. Provide a descriptive name under **Process name**
4. You may add a description under **Process description**. We strongly encourage you to use the description to provide details about your process.
5. Click on the link **Change** beside Icon to select the icon best suited for your process.

![express-workflow-properties](images/express-workflow-properties.png)

6. The first process step is already available for configuration.
7. You may add further process steps using the button **Add process step**
8. You may delete unnecessary process steps using the button **Remove process step**
9. For each process step:

   * Select the **Task Type**

      |**Task type**|**Description**|
      | ----------- | ------------- |
      |**User Task**|For this task the user can define a UI|
      |**User Task with Email**|In addition to the normal User Task, the user can send an Email directly from the Axon Ivy Portal, without the need to change to another system|
      |**Information Email**|This email can be defined by the creator of the Express Workflow and will be sent automatically without user action|
      |**Approval**|This task type creates a approval task|

   * Provide a descriptive name in **Task Name**
   * Provide an optional description in **Task description.**

10. For *One time* process type, the first process step defines the users or roles under **Able to start** who can start the process

![able-to-start](images/able-to-start.png)

11. For all other process steps define the user or roles who are responsible to execute the task in **Responsible**.

![responsible](images/responsible.png)

12. For each process step except the first define the time before the task expires in **Expiry in days**
13. After finished define all the steps, click the **Next** button to configure each step details

![express-preview](images/express-preview.png)

#### Configure process steps

![express-add-input](images/express-add-input.png)

If the Express process has a step of type **User Task** or **User Task with Email**, the **Form definition** page will be opened. With this editor, you can create UI for each task of the mentioned types. The **Form definition** already provided necessary UI element which you can add freely to the UI of the process step.

   |**UI element**|**Description and options**|
   | --------------- | ------------------------- |
   |**Input field**|Input field for text, numbers or dates  <br>   - Text field  <br>   - Number field  <br>   - Date picker|
   |**Input area**|Text input field between 1 and 10 rows|
   |**Checkbox**|List of elements which allows the user a multiple selection|
   |**Radio button**|List of elements which allows the user a single selection|
   |**File Upload**|Provides a file upload dialog to the user. You may define:  <br>   - Allowed file types <br>   - Number of allowed attachments|

1. Choose one UI element and configure it. Each UI element has its own configurations.
   For example, if you want to add an **Input field** , you could configure it as below:

   * Provide a descriptive name for the input in **Label**
   * Select the input type in **Input type**
   * Indicate whether the input for this data item is required by toggle the switch **This field is required**

2. After you finished with configuring settings, click the **Create** button to add the UI element to the **Form elements** list
3. For each UI elements in the **Form elements** list, you can click the trash button to delete them
4. To configure the position of UI elements on the process step layout, drag and drop each UI element from the **Form elements** list into one of the areas of the **Placement of form elements** section
5. Click the **Preview** button on the top of the **Placement of form elements** section to see the preview version
6. For the steps of type **Information E-Mail**, the Email editor will appear instead. You can configure information for the email step here

   * **E-Mail address**: Email of recipients. Separate by comma.
   * **Response to**: The response email address. This field is optional.
   * **Subject**: The email subject.
   * **Email text**: Content of the email.
   * **Attachment**: Attachments you want to send together with the email. This field is optional.

7. Once you finish configure UI for a step, click the **Next** button to define the next step

#### Express Business Summary

Since version 12.0.0, Axon Ivy Express can operates independently from Axon Ivy Portal. But to manage Axon Ivy Express cases and tasks, it's strongly recommended to use Portal. By using Portal, you can check the summary data of each Express case by accessing the **Business Details** page of that case in the Portal.

#### Express Management

Express Management enable you to manage Express processes efficiently. Furthermore, you can import/export Express workflows using JSON files.

![Express management](images/express-management-process.png)

To use all features of the Express Management page, and start all Express processes, you need to be granted the role **AXONIVY_EXPRESS_ADMIN**.

##### HowTo: Export an Express workflow

1. In the Express workflows table, locate the desired workflow and click its menu icon.
2. From the dropdown menu, select **Export**.

![export-express](images/export-express.png)

The workflow will be automatically downloaded as a JSON file.

**Important**: The exported file is a JSON document containing the version information of Axon Ivy Express and the Express process data. Avoid editing this file manually to ensure data integrity.

##### HowTo: Import an Express process

The Import Express Process function allows the Administrator to import Express processes into the Portal from a backup JSON file.
Click the **Import** button, the Import Express Processes dialog will display. You can click the **Select** button and choose the Express JSON file that contains the workflows you want to import.

![import-express-dialog](images/import-express-dialog.png)

Then, press the **Deploy** button and wait for the deployment process.

![import-express-action](images/import-express-action.png)

After the deployment process is completed, an output log panel will be displayed. You can see all the information collected during the deployment process.

Now, if the deployment process is successful, your workflows are imported and an administrator can check and/or edit them before they are ready to use.

![import-express-status](images/import-express-status.png)

## Migration

### Migrate to 12.0.0

**Axon Ivy Express** is now a standalone application and no longer requires Axon Ivy Portal. Additionally, it has been updated to align with the latest structure of the Axon Ivy Market project template.

**Important**: Workflows created in previous versions of Express are incompatible with Axon Ivy Express 12. To continue using your old workflows:

   1. Export all workflows from the previous version.

   2. Import them into the new Axon Ivy Express using the [Import workflow](#howto-import-an-express-process) feature.
