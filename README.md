# Axon Ivy Express

[![CI Build](https://github.com/axonivy-market/axonivy-express/actions/workflows/ci.yml/badge.svg)](https://github.com/axonivy-market/axonivy-express/actions/workflows/ci.yml)

Axon Ivy Express is an add-on module for Axon Ivy. As a business user, it enables you to create and share your process applications with your colleagues. These capabilities are also known as No-Code Application Platforms or Citizen Developer Platforms.

How to use the [Axon Ivy Express](axonivy-express-product/README.md).
